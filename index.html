Camarda Homelab

Camarda Homelab é o servidor doméstico de uso privado de uma única pessoa, com serviços pessoais como o app de finanças Camarda Wallet. Não é distribuído ao público e não tem cadastro de usuários.

A autorização do Google é usada só para uma coisa: enviar cópias de segurança, criptografadas, dos dados desse servidor para o Google Drive do próprio dono, e lê-las de volta se for preciso restaurar.
