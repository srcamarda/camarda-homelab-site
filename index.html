Camarda Wallet

Camarda Wallet é um app de finanças pessoais de uso privado, mantido por uma única pessoa para controlar as próprias contas. Não é distribuído ao público e não tem cadastro de usuários.

A autorização do Google é usada só para uma coisa: enviar cópias de segurança, criptografadas, do banco de dados do próprio dono para o Google Drive dele, e lê-las de volta se for preciso restaurar.
